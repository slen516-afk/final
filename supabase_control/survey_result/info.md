# 問卷調整說明

## 目的

本文件旨在說明問卷介面及資料處理所需的調整事項。

## 當前資料處理說明

目前問卷輸出格式為 JSON，將直接送入大型語言模型（LLM）進行分析。請務必注意，在進行任何修改時，不可更改 JSON 格式。

## 前端介面調整需求 - 第一題區分類別

請前端團隊協助調整問卷第一題的呈現方式，將原先三個自填部分改成下拉式選單，選單的選項區分如下：

### 選單一：前端語言
frontend_langs = ['javascript', 'typescript', 'html', 'css']

### 選單二：後端語言
backend_langs = ['java', 'go', 'python', 'c#', 'rust', 'php']

### 選單三：資料科學語言
data_langs = ['r', 'sql', 'julia']

上述三類語言將被納入不同的技能維度進行評估。
