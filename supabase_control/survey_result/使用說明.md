# test_logic.py 使用說明

## 功能說明

`test_logic.py` 是一個職涯分析問卷計算器，可以：
- 讀取問卷填寫的 JSON 資料
- 計算六個維度的向量分數（D1-D6）
- 產生準備送給 LLM 的完整 payload

## 六個維度說明

- **D1: 前端** - 前端開發能力（Q2 + Q1前端語言）
- **D2: 後端** - 後端開發能力（Q3 + Q1後端語言 + Q4關聯式資料庫）
- **D3: 維運** - DevOps 與維運能力（Q5 + Q9）
- **D4: 數據** - AI/數據科學能力（Q6 + Q4向量資料庫 + Q4 NoSQL）
- **D5: 品質** - 程式碼品質與安全意識（Q7 + Q10 + Q12）
- **D6: 軟實力** - 溝通協作與學習能力（Q11 + Q13 + Q14 + Q15）

## 使用方法

### 方法一：從 JSON 檔案讀取資料（單一使用者）

```bash
python test_logic.py -i example_input.json
```

### 方法二：讀取資料並儲存結果到檔案（單一使用者）

```bash
python test_logic.py -i example_input.json -o result.json
```

### 方法三：批量處理多個使用者（陣列格式）

```bash
# 如果輸入檔案是陣列格式 [user1, user2, ...]，會自動批量處理
python test_logic.py -i out_put.json -o batch_result.json
```

**批量處理說明：**
- 輸入檔案可以是單一使用者物件 `{...}` 或多個使用者的陣列 `[{...}, {...}]`
- 程式會自動偵測格式：
  - **單一物件**：輸出單一結果物件
  - **陣列格式**：輸出結果陣列，每個使用者一個結果
- 批量處理時會顯示處理進度 `[1/3] 處理中...`
- 如果某個使用者處理失敗，會標記錯誤但繼續處理其他使用者

### 方法四：只顯示分數（不顯示完整 payload）

```bash
python test_logic.py -i example_input.json --scores-only
```

### 方法五：使用預設測試資料

```bash
python test_logic.py
```

## 輸出說明

### 終端機輸出

**單一使用者模式：**
- 顯示六個維度的分數（D1-D6）
- 顯示完整的 LLM payload（包含計算結果和原始輸入）

**批量處理模式：**
- 顯示每個使用者的處理進度 `[1/3] 處理中...`
- 顯示每個使用者的分數
- 顯示處理完成摘要（總數、成功數、失敗數）
- 顯示第一個使用者的完整 payload（作為範例）

### 檔案輸出（使用 -o 參數）

**單一使用者輸出格式：**
```json
{
  "radar_scores": {
    "D1": 2.5,
    "D2": 3.0,
    ...
  },
  "llm_payload": {
    "calculated_vectors": {...},
    "user_raw_input": {...}
  }
}
```

**批量處理輸出格式（陣列）：**
```json
[
  {
    "radar_scores": {...},
    "llm_payload": {...}
  },
  {
    "radar_scores": {...},
    "llm_payload": {...}
  }
]
```

- 儲存為 JSON 格式
- 單一使用者：單一物件格式
- 批量處理：陣列格式，每個元素對應一個使用者的結果

## 範例

### 範例一：單一使用者處理

查看 `example_input.json` 檔案作為單一使用者輸入格式範例。

```bash
python test_logic.py -i example_input.json -o result.json
```

這會：
1. 讀取 `example_input.json`（單一使用者）
2. 計算六個維度的分數
3. 在終端機顯示結果
4. 將結果儲存到 `result.json`（單一物件格式）

### 範例二：批量處理多個使用者

如果您的輸入檔案是陣列格式（如 `out_put.json`）：

```bash
python test_logic.py -i out_put.json -o batch_result.json
```

這會：
1. 讀取 `out_put.json`（多個使用者的陣列）
2. 自動偵測為批量處理模式
3. 逐一處理每個使用者並計算分數
4. 顯示處理進度和摘要
5. 將所有結果儲存到 `batch_result.json`（陣列格式）

**輸出檔案格式：**
- 單一使用者輸入 → 單一物件輸出
- 陣列輸入 → 陣列輸出（每個使用者一個結果物件）
