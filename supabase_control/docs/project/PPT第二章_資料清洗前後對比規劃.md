## 三、如何截圖「原始 CSV 醜樣子」做清洗前後對比

要讓聽眾一眼看出「清洗前長怎樣」，建議截圖**小範圍、重點欄位**即可，不必整份 CSV。

### 方法一：用樣本表截圖（推薦）

1. **產出樣本檔**（在 `supabase_control` 下執行）：
   ```bash
   python scripts/ppt_export_raw_sample.py
   ```
   會產生 **`data/ppt_raw_sample.csv`**（約 6 筆、6 欄：職缺名、公司名、公司網址、薪資、地點、工作內容摘要），UTF-8 BOM，Excel 可正確開啟。

2. **用 Excel 開啟** `data/ppt_raw_sample.csv`：
   - 欄寬拉成「剛好看得清、不撐滿投影片」。
   - **凍結首列**（檢視 → 凍結窗格 → 凍結頂端列），標題列固定。
   - 截圖時只截**前 4～6 列 + 標題**，讓畫面同時出現：
     - **薪資**：`待遇面議`、或 `月薪 29,500~…`（格式不一）
     - **公司網址**：`(空)` 或空白
     - **地點**：`台北市大安區…`、`新北市板橋區…`（長短不一、未拆 city/district）
     - **工作內容**：一段文字被截斷成「…」，表現原始欄位過長、未整理

3. **放上 PPT**：這張圖當「**清洗前**」；右側或下一張放 Supabase Table Editor 或 SQL 查詢結果（`salary_min` / `salary_max`、`city`、`district`、`full_address` 已填滿）當「**清洗後**」。

### 方法二：直接截原始 CSV（表現「真的原始」）

- 用 **記事本** 或 **VS Code** 開啟 **`data/jobs_rows.csv`**。
- 不要開太多行，只截**前幾行**（含標題 + 1～2 筆），讓聽眾看到：
  - 逗號分隔、欄位很多
  - 同一格裡有換行（`job_description` 多行）
  - 薪資寫「待遇面議」、公司網址為空
- 適合「強調原始檔就是長這樣、未經整理」的對比。

### 對比時建議

- **左（或上）**：原始 CSV 醜樣子（上述任一種）。
- **右（或下）**：清洗後同一類資訊的整齊樣子（例如 Supabase `job_posting` 的 `salary_min`、`salary_max`、`full_address`、`city`、`district` 幾欄，或用你之前提供的 SQL 查詢結果截圖）。
- 口頭可說：「左邊是爬蟲回傳的原始欄位，右邊是經過清洗、寫入 DB 後同一筆職缺的結構化欄位。」

## 四、如何取得「清洗前／清洗後」數值

1. **清洗前**  
   在 `supabase_control` 目錄執行：
   ```bash
   python scripts/ppt_cleaning_before_after_stats.py
   ```
   輸出中的「清洗前」數字直接填進上表。

2. **清洗後**  
   跑完 `clear.ipynb` 至「階段五：資料驗證與統計」後，從輸出取得：
   - 職缺筆數：`【職缺】 總數 16,344`
   - 有 salary_min：`有 salary_min: 16,344` → 比例 100%
   - 有 full_address：同上
   - 公司有明確產業：`有明確產業（非未分類） 5,196`，總公司數 5,668 → 5,196/5,668 ≈ 91.7%

若你有做產業標註驗證（例如 88% 正確率），可在表內「清洗後」加一列「industry 分類正確率：88%」並在備註註明「依實際抽樣結果填入」。

## 五、講解要點（口頭說明建議）

1. **問題**  
   原始 CSV 有缺失、重複、薪資多為「面議」、地點與公司名不統一，無法直接給演算法或評審用。

2. **做法**  
   四大類：文字與欄位整理、公司與產業歸類、薪資與遠端欄位、去重與寫入；九階段實作收斂成這四類，不展開細部。

3. **對比表**  
   用「職缺筆數、有薪資區間比例、有描述／地點比例、產業覆蓋」讓聽眾一眼看出：筆數因去重與剔除空值略減，但**可用欄位完整度**（薪資區間、描述、地點、產業）明顯提升。

4. **結果**  
   清洗後寫入 DB，必填欄位無缺失、薪資可比較、地點可篩、產業可分析，達到「可直接給演算法與評審用」的等級。
